# BH List · 使用说明

把 QQ 群里的通知，自动收成一张张待办卡片。数据只存在你自己的手机上。

---

## 一、怎么安装

1. 把 `dist/BH List-v1.0.1.apk` 传到手机。
   - 微信/QQ 直接发 APK 可能会被拦截，建议用**数据线拷贝**、手机浏览器下载，或网盘。
2. 在手机上点开这个 APK。
3. 如果提示「禁止安装未知来源应用」，按提示允许一次即可。
4. 安装完成后，桌面会出现蓝色图标的「BH List」。

> 更新版本时直接覆盖安装即可，数据不会丢。前提是每次都用同一个签名证书（见文末）。

---

## 二、第一次打开：跟着引导做 5 步

1. **通知使用权**（最重要）
   点「去开启」→ 找到「BH List」→ 打开开关。
   没有这一步，群消息不会自动进来。
2. **允许发送通知**
   到截止时间要提醒你。
3. **精确提醒 + 忽略电池优化**
   不然国产手机省电策略可能让提醒晚到。
4. **在 QQ 里打开「显示消息详情」**
   QQ → 设置 → 消息通知 → 打开「显示消息详情」。
   不打开的话，通知栏只有「你收到一条消息」，软件拿不到内容。
5. **记住两点**
   - 群里设了「免打扰」→ QQ 不弹通知 → 软件抓不到。
   - 通知里只有文字，图片要手动导入。

引导可以随时在「设置 → 关于 → 使用引导」里再看一遍。

## 三、日常怎么用

### 收到群消息
QQ 弹通知后，消息会自动存进「待整理」。首页顶部会出现：

> 待整理 12 条消息 ›

点它进入待整理页，可以先划掉不关心的闲聊，再点底部：

> 整理成待办（12 条）

软件会把这段时间的消息合并成几条待办，给你预览。每一条都能改标题、改内容、设截止时间，删掉误判的，最后点「保存」。

### 在首页
- **点卡片**：编辑
- **点左边方框**：标记完成 / 取消完成
- **点右边 ⋮ 或长按**：置顶、删除
- **删除后**：底部会弹出「撤销」，点一下就能恢复
- **顶部搜索图标**：搜索标题、内容、群名
- **顶部「已完成」**：查看处理完的事
- **右下角 +**：手动新建待办（可以加图片）
- **群标签**：只看某个群的事

### 手动导入消息
- 在 QQ 里长按消息 → 分享 → 选择「BH List」
- 或复制文字后，在「待整理」页点「粘贴导入」
- 图片：在编辑页点「添加图片」，从相册选

### 导入聊天截图
在「待整理」页顶部点「选择截图」，从相册选一张 QQ 聊天记录截图。
软件会用手机本地的中文识别模型把截图里的文字提出来（离线，不联网），
识别出的内容进入「待整理」，再点「整理成待办」即可。
QQ 里长按图片选择「分享」到 BH List 也可以。
截图会随生成的待办一起保存，在待办详情里能回看。

### 截止提醒
识别到「周五前」「11月20日 18:00」这类时间后，会在到期前提醒（默认提前 1 小时）。
可以在「设置 → 提醒」里改成到点、提前 10 分钟、1 小时或 1 天。
不想被打扰时，把「设置 → 提醒 → 截止提醒」关掉即可：所有已安排的闹钟会取消，
截止时间仍会显示在卡片上；重新打开后会按截止时间重新安排。
只在手机上本地提醒，不联网。

## 四、开启 AI 总结（可选，不开启也能用）

不填 Key 时，软件用本地关键词规则整理（免费、离线，但笨一些）。
开启 DeepSeek 后，它会理解上下文、自动合并同一件事、提取截止时间，效果明显更好。

1. 打开 https://platform.deepseek.com ，注册并登录。
2. 进入「API Keys」→ 创建一个 Key → 复制以 `sk-` 开头的字符串。
3. 打开BH List → 设置 → AI 总结 → 打开开关。
4. 把 Key 粘贴到「DeepSeek API Key」，点「保存」，再点「测试连接」。
5. 看到「连接成功」就可以了。

费用：DeepSeek 按使用量计费，价格以官网为准；日常整理群消息的消耗很小。
隐私：只有开启 AI 并点「整理」时，那批消息才会发送给 DeepSeek；平时完全本地。

## 五、抓不到消息？按顺序检查

1. **这个群是不是设置了免打扰？** 免打扰的群不会弹通知，任何软件都拿不到。取消免打扰，或把这个群单独设为「接收消息但不提醒」（以 QQ 当前版本为准）。
2. **QQ 的「显示消息详情」开了吗？** 设置 → 消息通知 → 显示消息详情。
3. **通知使用权还开着吗？** 设置 → 消息抓取 → 通知使用权；有的手机清理后台后会关掉。
4. **软件被系统杀了？** 设置 → 关于，给BH List开「自启动」「后台运行」；小米/OPPO/vivo/华为尤其需要。
5. **只抓开启之后的新消息。** 安装前的老消息不会补抓。
6. 仍然不行：设置 → 诊断 → 复制诊断信息，发给开发者排查。

## 六、数据与隐私

- 待办、消息、图片全部存在手机本地，不上传服务器。
- 关闭 AI 时，软件不联网（除了你自己触发的测试）。
- API Key 用安卓系统密钥库加密后保存。
- 卸载 App 会清空所有数据；删除的待办保留 7 天后自动清理。

---

## 七、重要：备份签名证书

以后要出「可以覆盖升级」的新版本，必须用同一个签名证书。
请备份下面两个文件（不要只留 APK）：

- `keystore/release.jks`（签名证书）
- `keystore.properties`（证书密码）

丢了它们，新版本只能卸载旧版再装，旧数据会丢。

## 八、常见问题

**Q：为什么图片抓不到？**
A：安卓通知里只有文字，QQ 不把图片放进通知。需要从 QQ 分享图片到 BH List，或在编辑页从相册添加。

**Q：截图里的文字能识别吗？**
A：可以。在「待整理」页点「选择截图」，或从 QQ 分享图片到 BH List；软件会离线识别中文，识别结果进入待整理，再整理成待办。识别效果取决于截图清晰度，模糊或花哨的聊天背景可能识别不全。

**Q：为什么整理出来的待办不准？**
A：本地规则靠关键词；填了 DeepSeek Key 会明显更准。预览页可以随手改，改完保存就行。

**Q：能不能自动生成待办，不用我点？**
A：现在故意不做，因为群里闲聊多，自动生成会很吵。当前流程是「攒一批 → 你点一下整理 → 预览确认」。

**Q：会耗电吗？**
A：通知监听是被动接收，平时几乎不耗电；AI 只在点「整理」时联网几秒。
